# iDOMO · 样式生产一站式工作台

> 商业产品团队的AI工作台 · 用自然语言+组件化数据驱动模板从洞察到生产的闭环

## 在线 Demo

打开 GitHub Pages 链接（部署后填入）：

**https://你的用户名.github.io/formhub-demo/**

## 包含内容

- `index.html` — 首页（产品介绍 + 架构图 + 落地路径）
- `demo0-交互模式.html` — AI对话→工作流的完整流转
- `demo1-洞察归因.html` — 组件归因 + 提效建议
- `demo2-规则配置.html` — 引导式配置 + 冲突校验
- `demo3-全景总览.html` — 流量/预算/自定义视角

## 技术栈

纯静态 HTML + CSS + JavaScript，无外部依赖，可直接双击打开。

## 本地预览

```bash
git clone https://github.com/你的用户名/formhub-demo.git
cd formhub-demo
open index.html
```

## 设计目标

解决商业产品团队三个痛点：
1. **信息分散** — 模板生产、规则配置、效果数据、问题排查分散在多个平台
2. **门槛高** — 配置依赖人工记忆标签ID、规则冲突靠人肉排查
3. **洞察断** — 模板表现好坏看不到"为什么"，优化靠经验拍脑袋
